Java Client to interact with MongoDB from karate.

It provides features to execute operations such as count, find, insert and insertMany, replace, delete and deleteMany over MongoDB collections.

  • How to set it up:

    • Define (if applicable) the MongoDB client dependencies in the project POM

    • Define the MongoDB client configuration in the file src/test/resources/config/db/mongodb-<env>-config.yml

  • How to use it in the karate files:

    • MongoDB Client Features and Usage
