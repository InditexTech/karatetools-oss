Architecture

Karate Tools architecture

How Karate Tools is built: its modules, and how they fit together.

This page describes the modules that make up Karate Tools and how they relate to each other.

Overview

The high-level architecture of Karate Tools is shown in the following diagram:

Project structure

Module Description

Karate Tools Archetype

Archetype to initialize a Karate Maven project from scratch with all its dependencies.

Karate Tools Open API Generator

Automatic generation of tests in Gherkin, with their related data sets and schemas for response validation, as well as data to mock external services from Open API definitions.

Karate Clients

Clients to interact with relational databases (JDBC), a non-relational database (MongoDB), event messaging (Kafka consumer and producer) and JMS messaging.

For the repository’s own module-by-module breakdown (the code that implements Karate Tools itself, as opposed to the modules a Karate Tools user works with), see Contributing > Development.
