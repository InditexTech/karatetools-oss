<7> `antora.yml` (reserved file name): Antora component version descriptor file. This file indicates to Antora that the contents of a directory named `modules` should be collected and processed.
<8> `modules` (reserved directory name): Antora required directory located at the same hierarchical level as the `antora.yml` file — `ROOT` (the home page only) and `main` (every other page).
<9> Supplemental UI assets (logo, favicon) layered on top of the docouture UI bundle.
