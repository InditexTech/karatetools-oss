* xref:guides/clients/jdbc.adoc[*JDBCClient*]: Java Client to interact with DataBases using JDBC. Included drivers for:
** MariaDB
** PostgreSQL
* xref:guides/clients/mongodb.adoc[*MongoDBClient*]: Java Client to interact with MongoDB
* xref:guides/clients/kafka.adoc[*Kafka Clients*]: Java Clients (Consumer and Producer) to interact with Kafka
* xref:guides/clients/jms.adoc[*JMSClient*]: Java Client (JMS Send and JMS Consume) to interact with JMS queues. Included providers for:
** Rabbit MQ
** Apache Active MQ
