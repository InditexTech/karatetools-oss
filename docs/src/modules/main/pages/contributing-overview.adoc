We welcome contributions to Karate Tools — from bug reports and typo fixes to
new features.

== Ways to contribute

* *Report a bug* — open an issue in our
  link:https://github.com/InditexTech/karatetools-oss/issues[issue tracker].
* *Suggest a feature* — open an issue explaining your idea.
* *Contribute code* — read the xref:development.adoc[development guide] below.
