[#docs-local-build]
To locally build the documentation, you can use the following commands from
the `docs` directory:

[source,shell,subs="+attributes"]
----
npm install
npm run dev
----

This starts `docouture dev`, which builds the site and serves it at
`http://localhost:5000` with live reload — pass `--port` to use a different
one. See xref:development.adoc[Development] for the full command set
(`docouture build`, `docouture doctor`, releasing, publishing).
