= Generators module
:description: The karatetools-oss-generators module.

The `karatetools-oss-generators` module includes the following packages:

* 📦 `dev.inditex.karate.openapi`: *Open API generator* to create *test scenarios*, *test data* and *external services mocks* from *Open API* specifications.
* 📦 `dev.inditex.karate.console`: *request user input from the console* (which API specification file to use, which operations to generate, etc).
