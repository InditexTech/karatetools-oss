✔️ Karate Tools - Fixed the *OpenAPI generator interactive console on macOS Apple Silicon*.

| 5.2.0
| 2026-03-03
|

✔️ Karate Tools - Fixed Open Api Generation - Operation ID Sanitize

👉 Added configurable `open-api-operation-id-sanitize.mode` Maven property (default: `alphanumeric`). See xref:guides/open-api-generator/overview.adoc#operation-id-sanitize-mode[Open API Generator - Configuration - Operation ID Sanitize Mode].

👉 Supported modes: `alphanumeric` (removes non-word characters, preserves digits and underscores) and `letters-only` (keeps only `[a-zA-Z]` characters).

👉 The property is forwarded as a JVM system property via `exec-maven-plugin` and can be overridden at the command line with `-Dopen-api-operation-id-sanitize.mode=<mode>`. See xref:guides/open-api-generator/overview.adoc#execution[Open API Generator - Execution].
