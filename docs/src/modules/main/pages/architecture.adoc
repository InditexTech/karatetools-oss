== Project structure

[cols="40,~"]
|===
|Module |Description

|xref:guides/archetype/overview.adoc[Karate Tools Archetype]
|Archetype to initialize a Karate Maven project from scratch with all its
dependencies.

|xref:guides/open-api-generator/overview.adoc[Karate Tools Open API Generator]
|Automatic generation of tests in Gherkin, with their related data sets and
schemas for response validation, as well as data to mock external services
from Open API definitions.

|xref:guides/clients/overview.adoc[Karate Clients]
|Clients to interact with relational databases (JDBC), a non-relational
database (MongoDB), event messaging (Kafka consumer and producer) and JMS
messaging.
|===

For the repository's own module-by-module breakdown (the code that
implements Karate Tools itself, as opposed to the modules a Karate Tools
user works with), see
