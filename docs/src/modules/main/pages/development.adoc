= Development
:description: Set up a development environment and work on Karate Tools.

This page explains the process of implementing new features or fixing bugs
in the Karate Tools ecosystem, and points you at the
xref:contributing/repo-structure/overview.adoc[repository structure] and the
xref:contributing/step-by-step.adoc[step-by-step guide]. For the
contribution process itself (issues, pull requests), see
xref:contributing-overview.adoc[Contributing].

== Development process

The steps to follow are:

* Implement the new feature or fix the bug.
* Perform the necessary tests:
** create or update the corresponding *unit tests*, execute them, and
   verify that they pass and that the code coverage is over the established
   threshold ({karatetools-unit-coverage-threshold});
** execute the *mutation tests*, verify that they pass and that the
   mutation coverage is over the established threshold
   ({karatetools-mutation-coverage-threshold});
** create or update the corresponding *integration tests*, execute them,
   and verify that they pass and that the code coverage is over the
   established threshold ({karatetools-integration-coverage-threshold});
** create or update the corresponding *Karate tests*, execute them, and
   verify that they pass and that the code coverage is over the
   established threshold ({karatetools-karate-coverage-threshold}).
* Update the relevant documentation.

== Environment setup

See xref:prerequisites.adoc[Prerequisites] for the tools and versions
required, and xref:contributing/repo-structure/docs.adoc[the docs module]
for how to build this documentation site locally.

== Testing

See each xref:contributing/repo-structure/overview.adoc[repository module]'s
own page for its testing instructions — unit and mutation tests for the
`code` modules, integration tests in `karatetools-oss-boot`, and Karate
tests in `karatetools-oss-karate-test`.

Once you're ready, follow the
xref:contributing/step-by-step.adoc[step-by-step guide] to submit your
contribution.
