== Recommended path

To set up a Karate project for testing a REST artifact, follow these steps:

. Ensure the xref:prerequisites.adoc[prerequisites] are met.
. Run the xref:guides/archetype/overview.adoc[archetype] to set up the
  initial Karate project.
. Follow the xref:guides/configuration/overview.adoc[configuration] steps.
. Generate tests, data sets and mocks from Open API definitions with the
  xref:guides/open-api-generator/overview.adoc[Open API generator].
. Integrate xref:guides/clients/overview.adoc[Karate clients] in the tests
  for test data preparation and test validation.
. Follow the xref:guides/execution/overview.adoc[execution] instructions:
  running, reporting, starting a local application and other utilities
  (KarateCache, ...).
